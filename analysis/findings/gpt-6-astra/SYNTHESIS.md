# Cross-paper synthesis

All 87 source reviews are complete: 84 catalogued papers, two inbox PDFs, and the current Continuous State, Bounded Computation draft. The strongest recurring recommendation is to make existing feedback signals, evidence revisions and task outcomes precise, then evaluate larger architectural additions at matched cost. [INDEX.md](INDEX.md) records coverage; [IMPLEMENTATION.md](IMPLEMENTATION.md) supplies the common static code evidence. No proposed implementation change or runtime experiment was performed in this review.

[Deep findings](DEEP_FINDINGS.md) contains the separately curated conceptual insights; this document retains the broader implementation findings and experimental directions.

## Implementation priorities

These priorities reflect the completed corpus and the implementation master’s source traces. They are recommendations for future work, with the smallest well-specified interventions and independent outcome measurements first.

| Work | Why it comes early | Evidence and boundary |
|---|---|---|
| Establish source-recall and outcome fixtures with complete, isolated state. | Ranking, reflection, and rehearsal comparisons otherwise conflate changed evidence, changed retrieval state, and added computation. | QMEM/Q53/Q58/Q64; native and executive stores both matter. |
| Resolve the native ordering and ACTIVATE packing contract. | Relevant scores are already computed but cannot order distinct records after the unique-ID tie-break. This offers a small intervention to compare before adding inference or new indexes. | Q57D; preserve active-status filtering and measure actual recall effects. |
| Verify and enforce intended execution effects at the service boundary. | The observe label does not itself restrict model-selected shell commands to read-only effects. | Q65; account/resource limits are real, deployed authority remains unverified. |
| Make corrected evidence reachable and track dependent interpretations. | Existing explicit replacement works, but deciding replacement, propagating correction, and rehearsing fresh evidence through old cues are separate mechanisms. | Q35/Q38/Q57S/Q57D; use the existing reasoning budget where possible and keep rehearsal distinct from independent support. |
| Make mental-state evidence distinguish competing contents. | The current belief/goal/plan forecasts can assign identical likelihood evidence to incompatible same-kind propositions. Better scoring of coarse activity does not resolve that semantic ambiguity. | Q21S/Q71/Q81; retain existing coarse forecasts and proper scoring while separately testing content-conditioned action predictions. |
| Connect observed outcomes to state revision, repair, and measured usefulness. | Plans, results, repair proposals and learning records already exist; several missing consumers prevent a closed, attributable feedback loop. | Q06/Q34/Q48/Q54/Q60; task achievement must remain distinct from adapter success and internal acceptance. |
| Admit larger memory, curriculum, and self-modification systems only after matched comparisons. | Many papers add useful machinery together with extra calls, changed task distributions or weak baselines. | Individual reviews specify controls; retained held-out capability per total cost is the common decision criterion. |

| Finding | Consequence for Navi-Brain | Evidence |

## Architectural implications

Several existing mechanisms learn from signals produced by other parts of the executive: queries strengthen associations, selected sensory events can earn usefulness credit, worker completion statistics influence appraisal, and completion judgments change intention state. These are concrete feedback loops. Their inputs need clear semantics and independent outcome checks if accumulated activity is to become evidence of improved competence. This is a synthesis of the source audit and completed reviews, not a causal result already demonstrated for Navi-Brain.

The social-model finding sharpens this hypothesis: identical forecasts can strengthen incompatible same-kind propositions. That channel measures the quality of a coarse prediction without discriminating the propositions' contents. Together with artifact-based need satisfaction and confidence-derived uncertainty reduction, this motivates a specific audit question: which credited changes depend on an observation capable of distinguishing improvement from merely more activity? Existing grounding checks, explicit corrections, delayed observation scoring, and typed procedural verification are useful boundaries to preserve. The proposed audit concerns the meaning of particular feedback signals, not a claim that all learning is ungrounded.

Q38 adds a concrete recursive path: accepted epistemic reflections can influence later reflection through semantic retrieval and carried beliefs. Its acceptance-event provenance does not provide the same support validation as episodic consolidation. Combined with Q35's missing general source-correction propagation, this makes grounding and revision of that existing loop a distinct priority from adding more reflection stages.

Persistence has three distinct requirements here: retaining a source, making it reachable through future cues, and revisiting it when the world can change. Q57D addresses access feedback; Q84 distinguishes configured sensory polling from task-specific object reinspection. A durable task can therefore require both rehearsal of relevant evidence and scheduled acquisition of new evidence. Neither replay nor a timestamp can substitute for observing an external change.

## Cheap, durable precedence for corrected rules

Aku's constraint is to improve replacement without an additional model call. Recency already gives newer material a ranking advantage; the missing semantic decision is whether it corrects the same rule, changes its scope, or merely adds another observation. Q57S confirms that explicit replacement already updates resident status and ordinary recall excludes superseded records. The proposed improvement should reuse that enforcement boundary.

A bounded candidate design is to have the existing authoring/reasoning step emit a canonical rule key, applicability scope, explicit predecessor ID/version, and correction evidence alongside the proposed text. Validate those fields against the current active predecessor and authorized source before committing replacement. A keyed current-version lookup would give declared rules durable precedence at small indexed-lookup cost, without asking another model to compare every retrieval result. Delayed proposals must not replace a newer version they never observed. Different scopes, historical validity intervals, and exceptions must remain distinguishable; sharing a token is insufficient evidence that two claims are alternatives.

The semantic work is still real: the existing reasoning call must identify the relationship, or an already structured source must supply it. Arbitrary natural-language contradiction detection is not obtained for free. Ambiguous relationships should remain unresolved rather than being converted automatically into latest-text-wins. Additional fields, validation, storage, and lookups also have nonzero cost; the target is no extra inference round and bounded work per declared replacement.

Evaluate direct replacements, paraphrased corrections, scope-limited exceptions, irrelevant newer facts, and stale concurrent proposals. Require the active answer to follow the justified current rule while historical queries can recover the earlier version. Measure subsequent behavior as well as retrieval eligibility. General reconsideration of dependent conclusions is a further requirement from Q35, with costs proportional to affected dependencies; it should not be claimed as a free consequence of this narrow mechanism. This is a proposed design from the review and user constraint, not an implemented change or a diagnosis of the supplied visualization.

## Freshness-weighted rehearsal through shared cues

Aku clarified that explicit replacement is only part of the issue: recently acquired evidence should receive offline rehearsal, become easier to reach through familiar tokens, and contribute to newly consolidated memories. Q57D identifies a concrete exposure feedback loop. Native retrieval prioritizes record access count before recency and token scores, after ACTIVATE-specific span criteria; ordinary recall has no span contribution. Returned records gain additional access counts, with no decay term in that comparator. PHP keyword reranking only sees the native top-k. Consequently, repeated access can entrench an older active candidate before the later lexical stage has a chance to compare it with fresh evidence. This is a static mechanism, not a reproduced diagnosis of the supplied screenshot.

A further comparator detail makes a cheaper control particularly important: `memory_updated_compare` already breaks timestamp ties by unique record ID, so the later direct-match and total-score branches cannot order distinct valid records. Query scores affect candidate construction, but their apparent ranking tie-breakers are ineffective. ACTIVATE still consumes direct-match score during packing, including an early break when the score differs from the first result in its no-span case; the candidate list is not ordered by that score. Q57D documents these exact boundaries. Correcting the intended ordering and packing contract is a narrower candidate intervention than adding rehearsal infrastructure, and its downstream effects remain unmeasured.

Existing daydreaming ranks semantic/episodic candidates, shuffles them, observes three, and creates a synthetic artifact. Consolidation starts with the oldest pending episode and includes bounded related material. These are real rehearsal/synthesis routes, but the inspected paths lack explicit freshness-weighted replay of old cues paired with new evidence. Blindly repeating ordinary recall can increase the already preferred records' access counts. RANK_RECORDS avoids those candidate counts but reinforces all traversed existing cue links; OBSERVE raises chosen records' access/read counts without creating new cross-record associations. Neither alone implements the proposed targeted relationship.

A bounded design could capture relevant old cues and source IDs during an already budgeted reasoning/consolidation call, then enqueue deterministic rehearsal work with a per-source exposure cap, freshness window, endpoint eligibility check and deduplication ledger. A native operation would need explicit semantics for applying that cue/evidence update. Record rehearsal exposure separately from independent support, and preserve source lineage when consolidation publishes new content. A fresh record's actual source may justify factual revision; rehearsal merely changes its accessibility. Generating meaningful new interpretations still consumes inference, even when scheduled within existing consolidation calls.

Before adding that operation, compare simpler alternatives on the same chronological evidence: current retrieval; bounded observation of fresh records; a revised ranking rule that limits cumulative-access dominance; and targeted cue/evidence rehearsal. Separate candidate-set reachability from ordering and downstream answer correctness. Include old-but-still-correct facts, fresh contradictions, justified corrections, and commonly repeated irrelevant material. Charge native CPU, storage and existing model tokens as well as any additional calls. Require improvement under the original old cues without increased unsupported assertions or loss of unrelated old knowledge. This provides a measurable interpretation of “computationally for free”: no extra inference round, bounded native work, and demonstrated benefit beyond a cheaper ranking change.
