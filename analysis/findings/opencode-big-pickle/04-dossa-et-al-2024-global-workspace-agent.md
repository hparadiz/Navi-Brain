# 04 — The workspace as a tight bottleneck: what the attention ablation actually buys

- **Paper**: Design and evaluation of a global workspace agent embodied in a realistic multimodal environment
- **Source**: Frontiers in Computational Neuroscience 18:1352685, 2024, DOI 10.3389/fncom.2024.1352685
- **Local file**: assets/papers/04-dossa-et-al-2024-global-workspace-agent.pdf

## Core idea

A concrete neural implementation of Baars' Global Workspace Theory that explicitly satisfies all four GWT indicator properties (plus two RPT properties) from Butlin et al. (2023): parallel specialized recurrent encoders for vision and audio, a limited-capacity central working memory as the workspace, a cross-attention gate (with a RIMs-style null input) enforcing the bottleneck, and the previous workspace state broadcast back into each encoder as recurrence. Trained by behavioral cloning on 500k oracle trajectories in the SoundSpaces/SAVi audiovisual-navigation task. Results: the global-workspace agent is more robust (~80% success) than the plain GRU baseline (~60%) *at small working memory sizes*; the gap vanishes as capacity grows. Probing and weight analysis show the bottleneck forces dynamic, cross-modal attention and that agents lean on the broadcast to carry information across time. The authors' own conclusion is the honest bit: the task is too easy to test working memory, larger agents gain nothing, and the indicator properties may be too coarse — the workspace's advantage shows only under real informational pressure.

## Relevance to Navi-Brain

This is the corpus paper the synthesis already leans on for the "limited-capacity workspace with discrete broadcasts" (§1) and the longitudinal metrics already name it as the spec behind "broadcast uptake," "content-specific causal effect," "workspace ablation delta," and "specialist unique contribution" (`docs/longitudinal-cognition-metrics.md` §Metric family 3). Its most transferable finding is about *pressure*: the workspace only earns its keep when it is genuinely small and the task genuinely requires cross-module integration — otherwise it is dead weight. That is a direct design rule for the workspace scheduler Navi-Brain has promised (implementation-order item 4) but not built. The paper also validates the evaluation philosophy Navi-Brain already committed to: probe the representations, ablate the broadcast, compare against shams.

  - **Specialist-like bounded workers.** `src/Core/FreeModelWorker.php` is a bounded proposal worker — the "specialized system operating in parallel" (GWT-1) in embryo, minus the competing coalition.
  - **The measurement spec.** Broadcast-uptake, sham-vs-matched causal effect, and workspace-ablation metrics are already written down (`docs/longitudinal-cognition-metrics.md:201-222`) and experiment 5's "proposal uptake" (`docs/experiments/05-cognitive-component-ablation.md:140-144`) says it: availability without causal uptake is not integration. That is Dossa's and LIDA's shared spine.
- Partially present:
  - **The bottleneck exists but does not select.** `attention_score` is computed and only used to order `top_appraisals` in `status()` (`ExecutiveCore.php:2177-2180`). It does not gate retrieval, worker selection, daydream scheduling, or memory retention. GWT-2's defining move — the workspace only *lets through* the most salient — is absent. The brain has a salience number and a serial selection point, and nothing joins them.
  - **Working memory tier.** The `working` memory tier (visible in `status()`) is a capped dump ordered by recency, not a bounded workspace with attention-gated intake. Dossa's whole point is that the *size and the gate* are what create pressure, not the storage.
  - **The design language is already in the brain.** Active intention #10's next-action text names "cheap specialist processes, workspace recruitment, and language-model escalation only when accumulated state warrants it" — the architecture doc (`docs/ongoing-cognition.md:253`) calls every invocation "a temporary workspace for advancing a thread." Design is there; substrate is not.
- Absent / open design:
  - **Broadcast feedback loop.** The paper's signature move — the previous workspace state fed back into each specialist encoder so past state shapes current processing (they even show agents prefer this channel over direct recurrence) — has no Navi-Brain analog. The ongoing-cognition "fresh context capsule" proposal is the closest intent, but today a worker wake gets a constructed prompt, not a broadcast that provably shaped the state it reads.
  - **Competition among proposals.** No mechanism where multiple candidates compete and a limited-capacity selection admits one winner to a shared surface every other consumer must read. `ThoughtArtifact` rows sit in `proposed` until someone promotes them.
  - **Learned representations / probing.** Nothing in Navi-Brain is trained, so representation-probing (their Section 2.8.2) doesn't transfer directly — but the *idea* of checking whether the internal state actually holds the information the task needs is exactly what the evidence+confidence rules on memory and self-model are a static version of.

## Concrete implications for implementation

- **Make `attention_score` a gate, not a display field.** Smallest honest change: let appraisal-weighted salience rerank retrieval (`memory:search`) and set high-brain work-item priority before the single-flight selection. That converts the existing serial bottleneck into a GWT-2-style selective-attention bottleneck without new architecture. Then measure it with the "appraisal causal value" style experiment (routing on vs. shuffled) already floated for LIDA.
- **Keep the workspace small on purpose.** The paper's ablation is the warning: at large sizes the workspace buys nothing. If and when a broadcast is built, start with one fenced work item and one consumer (consolidation), with a tight budget — not a roomy message bus. Tightness is a feature; it is what forces selection.
- **Wire the broadcast as feedback, not fan-out.** Dossa shows the win comes from the *previous* workspace state feeding the next cycle's processing, not from copying the current log everywhere. Map this onto `docs/ongoing-cognition.md`'s fresh-context capsule: include the last selected content and its downstream uptake in the next wake's context, and record which consumer actually used it (the existing "broadcast uptake" metric).
- **Add the sham/broadcast-uptake measurements to the longitudinal ledger as buildable, not aspirational.** Metric family 3's rows are the exact evaluation Dossa ran (ablation of the broadcast, content-specific effect). Mark them "blocked on substrate" so the metrics stop looking implemented.
- **Don't copy the training story.** Behavioral cloning and gradient-detached broadcast recurrence are about training a policy; Navi-Brain is hand-regulated. The transferable methodology is the *analysis* (IQM over seeds, probes, weight-magnitude checks), which the repo already mirrors in its CI/bootstrap discipline.

## Risks / tensions

- **Consciousness framing.** The paper is rigorously functionalist — the workspace is access consciousness, indicator properties, nothing phenomenal. Navi-Brain's invariant is the same ("no consciousness score," appraisal as routing signal). Fine. The risk is importing "global workspace agent" as a brand and drifting toward the synthesis's named failure mode of "consciousness theater" or treating structural resemblance as experience. Keep calling it a selection/routing bottleneck.
- **The evidence is genuinely thin.** One task, one imitation-learning dataset, five seeds, and their own admission that SAVi doesn't stress working memory and the advantage disappears at scale. This is a "here is a plausible mechanism and an honest ablation" paper, not validation that workspaces confer general benefit. Do not cite it as proof the broadcast must be built; cite it as proof that *pressure* is the variable that matters.
- **Central-workspace failure modes are already on the books.** The synthesis lists "a central workspace becomes a latency bottleneck or single point of failure" and "specialists learn to game salience and monopolize broadcasts" (`docs/literature-synthesis.md:231-232`). Dossa's dynamic-attention-at-small-bottleneck finding hints tight budgets curb the gaming; the single-point-of-failure risk remains Navi-Brain's existing fencing/single-flight defense.
- **Recurrence is unstable unless carefully gated.** The gradient-stop detail matters: feedback-through-the-workspace destabilized training until detached. That is a warning for wiring `CognitiveThread` loops into the low-brain path — keep them fenced and monotonic, don't let broadcast feedback create runaway amplification.

## Bottom line

Partially adopt — as the empirical case for building the bottleneck *tight* and for making `attention_score` a real selection gate, plus the measurement template for broadcast uptake. The single most important consequence: the paper confirms Navi-Brain's workspace should be a small, fenced, causally-audited selection bottleneck wired into existing work items and consolidation, and that until then the "workspace" metrics in `docs/longitudinal-cognition-metrics.md` are measuring a promise.
