# Record #52 — PMI: A Framework for Inference Inspired by Human Memory Mechanisms (Zeng et al., ICLR 2024)

## 1. Mechanism

PMI is a **replacement for the self-attention layer inside a Transformer** (and a
bolt-on after a CNN stack), not a memory system in the systems sense. Three
components (p. 2):

1. `P` (perception): standard embedding + positional encoding for text, or ViT
   patchify for images. `H = P(X)`. Nothing new here (p. 3).
2. `M` (memory): `M^t = M(H^{t-1}, M^{t-1})`.
3. `I` (inference): `U = I(H^{t-1}, M^t)`.

**Critical: `t` is the layer index, not time.** Algorithm 1 (p. 14) is written as
"Input to the layer l: h^{l-1}" and the same equations appear with `l`
substituted for `t`. The Initialization step initializes `Mw` and `Ml` per raw
input `X`, "guaranteeing their universal sharing across all layers" (p. 14). The
gating appendix confirms it decisively: memory carries a batch dimension,
`Mw^{t-1}, Mw^t ∈ R^{B×N×Dm}` (p. 18). A per-example tensor cannot persist
across examples. So the memory lives for one forward pass (8-16 layers) and is
destroyed. "Long-term" here means "survives 12 layers."

### Data structures

- Working memory `Mw ∈ R^{N×Dm}` — N slots, N=8 in every experiment (p. 3, Table 7 p. 19).
- Long-term memory `Ml ∈ R^{C×N×Dm}` — C "memory fragments," C (called M in tables) = 5 (p. 3, p. 19).

### Write to WM: competition (pp. 3-4)

Multi-head **sparse** cross-attention (MHSC). Slots are queries, perceptual
tokens are keys/values — the reverse of ordinary attention:

```
sk = softmax( Mw^{t-1} W^Q (h^{t-1} W^K)^T / sqrt(dK) )
```

Then a **top-k mask**: "Construct a set Ft containing the indices of the k
selected specialists with the top-k largest values of sk. s*k = s[n,t] if t ∈ Ft,
else 0, for all n ∈ {1,...,N}, t ∈ {1,...,T}" (p. 14). k=5 in all seven
experiments (Tables 7-8, p. 19). As written, `Ft` is one index set applied
across all slots `n` — a *global* winner set of k input positions, not per-slot
selection. The losing tokens are zeroed, not queued. This is the Global
Workspace "restricted write access" bottleneck, inherited from Goyal et al.
(2022) HSW and Ke et al. (2018) top-k softmax, both cited (pp. 3-4).

Then residual + LayerNorm + k stacked MLPs + LayerNorm (Eq. 3-5, p. 4).

### Forgetting: gating (Eq. 6 p. 4; detail p. 18)

```
X̄  = (1/T) Σ relu(X_i W^I)
K  = X̄ + tanh(Mw^{t-1}) W^F
I_t = sigmoid(K + b_i),  b_i = 0
F_t = sigmoid(K + b_f),  b_f = 1
Mw^t = I_t ⊙ tanh(M̃w^t) + F_t ⊙ Mw^{t-1}
```

Two things worth naming that the paper does not: (a) `I_t` and `F_t` are both
monotone functions of the *same* scalar field `K`, so they are correlated, not
complementary — a "salient" input raises both retention and writing; there is no
keep-vs-write trade-off. (b) `b_f = 1` biases the forget gate open, i.e. **retain
by default**; eviction is never forced by the gate, only by the fixed N slots and
LayerNorm.

There is **no time-based decay anywhere in the paper.** Ebbinghaus is cited (p. 5)
and never operationalized.

### Promotion WM -> LTM (Eq. 7, p. 4)

```
Ml^t = LN3( Mw^t ⊗ Ml^{t-1} ) + Ml^{t-1}
```

**Unconditional, every layer, no criterion.** The entire working memory is
outer-producted into LTM at every step. There is no threshold, no salience test,
no confidence gate, no eligibility rule. Whatever survived the perception->WM
competition is promoted automatically. Note also the equation is
dimensionally under-specified: `Mw ∈ R^{N×Dm}` outer `Ml ∈ R^{C×N×Dm}` — the
contraction/broadcast is never stated, and there is no eviction from LTM, only
additive accumulation.

### Retrieval and fusion (Eq. 8-12, pp. 4-5)

- WM read: `Uw = MHC(h^{t-1}, Mw, Mw)` — **dense**, no top-k (p. 4).
- LTM read: first collapse the 3D structure by a plain mean,
  `M̂l = (1/C) Σ_i Ml[i,:,:] ∈ R^{N×Dm}` (Eq. 9, p. 4), then
  `Ul = MHSC(h^{t-1}, M̂l, M̂l)` — **top-k sparse** (Eq. 10, p. 4).
- Correction: `Uwl = MHC(Ul, Uw, Uw)` — the LTM-derived reading forms the
  *queries* against the WM-derived reading as keys/values. LTM revises WM, not
  the other way (Eq. 11, p. 5).
- Blend: `U = α Uw + (1-α) Uwl`, α = 0.55-0.75, listed as "Initial α value"
  in Table 7 (p. 19) though the text calls it a hyper-parameter (p. 5) —
  the paper is inconsistent about whether α is learned.

So competition appears at two places: admission into WM (top-k over perceptual
tokens) and read out of LTM (top-k over memory content). Reading WM is
uncompetitive.

## 2. Transferable to Navi-Brain

Nothing here needs training to state as a policy, but nothing here was *measured*
outside a trained differentiable setting either. Transfer is by analogy.

**(a) A fixed-capacity thread working set with hard admission — the one real
mechanism.** New table, roughly:

```sql
CREATE TABLE thread_working_set (
  thread_id   INTEGER NOT NULL,
  slot        INTEGER NOT NULL,          -- 0..N-1, N = 8
  ref_kind    TEXT NOT NULL,             -- memory|observation|step|intention
  ref_id      INTEGER NOT NULL,
  admitted_at INTEGER NOT NULL,
  score       REAL NOT NULL,
  PRIMARY KEY (thread_id, slot)
);
```

Per cycle: score candidates, `ORDER BY score DESC LIMIT k` (k=5), write winners
into slots, **drop the losers rather than queueing them**. The primary key on
`(thread_id, slot)` is the capacity constraint — it is enforced by the schema,
not by a policy the worker could talk its way past. That property is the reason
to do it in SQL rather than in a prompt.

**(b) Retain-by-default eviction.** `b_f = 1` translates to: a slot is only
vacated when a candidate outscores its occupant. No age-out, no TTL. Concretely
`WHERE new.score > old.score` on the slot update, plus a small hysteresis
margin so a slot does not thrash between near-tied candidates. This is *not* a
decay schedule and should not be sold as one.

**(c) Asymmetric read discipline in the context capsule.** Include the working
set **in full** (dense read of WM), and only the **top-k** durable memories
(sparse read of LTM). This is a concrete capsule-builder rule and is the
cheapest thing on this list to implement: two queries with different LIMIT
semantics rather than one blended retrieval.

**(d) Combine, do not concatenate.** Eq. 11 says durable knowledge *queries and
revises* the current working view. Degraded version: durable memories enter the
capsule as **annotations attached to working-set items** (contradicts / confirms
/ supersedes / prior-outcome-of), not as free-standing paragraphs appended after
the recent context. Fixed slot budget weighted toward the working set, mirroring
α ≈ 0.7. Ablation `w/o2` (Table 5, p. 9) is the only evidence for this and it is
0.36 percentage points on a single seed — directional at best.

**(e) Capacity is not monotone.** Ablation: N=10/C=7/k=9 is *worse* than
N=8/C=5/k=5 on bAbI (2.62 vs 2.55) and on Sort-of-CLEVR binary (80.18 vs 87.61)
(Table 5, p. 9). Useful as a prior against "retrieve more into the capsule," but
see section 5 — this table has no repeats and the swings are almost certainly
within seed noise.

**Cheap degraded scoring.** PMI's competition scores by learned dot-product
attention over embeddings. Navi-Brain has no embedding index and does not need
one: score by `keyword_overlap * w1 + recency_decay * w2 + confidence * w3 +
intention_relevance * w4`, all computable in SQL from columns that already
exist. A local embedding model is possible but the paper gives no evidence that
learned scoring beats a hand-weighted one for a working set of 8.

## 3. Seam

`memory-tier` — primary. The WM/LTM split, the admission rule, the read asymmetry.
`context-capsule` — primary. The dense-WM / sparse-LTM / fuse-not-concatenate rule.
`thread-lifecycle` — the working set is thread-scoped state carried across steps.
`agenda-voc` — weakly. Top-k admission is a degenerate value-of-computation
selector: score candidates, take k, discard the rest without a backlog.

Not touched: `supervisor`, `worker-schema`, `curator-verification`, `authority`,
`self-model`, `perception`, `skill-library`, `metrics-benchmark`.

## 4. Challenge to the current plan

**Sharpest: this paper is evidence *against* the "fresh bounded context capsule
per operation" formulation, as literally stated.** The strongest ablation in the
paper is persistence: globally sharing one memory across all layers beats
per-layer independent memories by 7.32% (binary) and 6.88% (ternary) on
Sort-of-CLEVR, *while using 7x fewer parameters* (2.33M shared vs 16.48M
unshared, Table 5 p. 9; discussion p. 8, Fig. 5 p. 15). Rebuilding the working
state from scratch at every step was the losing condition. `docs/ongoing-cognition.md`
correctly rejects the growing transcript, but "fresh per operation" and "bounded
carried state" are different things and the doc collapses them. A fixed-capacity,
slot-addressed, overwrite-in-place working set is *not* a transcript: it cannot
grow, it has no history, and its size is a schema constraint. The plan should
distinguish (i) the transcript, which stays banned, from (ii) an N-slot thread
working set, which this paper's best result depends on.

**Second: do not cite this paper as support for durable cross-session memory.**
The memory has a batch dimension (p. 18) and is initialized per input (p. 14).
Its "long-term memory" persists for ~12 layers of one forward pass. Mapping
PMI's WM/LTM onto Navi-Brain's session-scratch vs SQLite `memories` table is a
category error the paper's own pseudocode refutes. What PMI actually validates
is a *two-tier scratch hierarchy inside one episode*. If a design doc reaches
for record #52 to justify the durable tier, that is an invalid citation and
should be caught in review.

**Third: PMI's consolidation is strictly worse than `memory:consolidate` and
should not influence it.** Promotion is unconditional (Eq. 7 p. 4), lossy
(outer-product superposition with no way to recover a constituent), and the read
path then destroys the "higher-order structure" the paper advertises by taking a
plain mean over the C fragments before attending (Eq. 9, p. 4). There is no
provenance, no confidence, no supersession, no contradiction detection. Navi-Brain's
existing consolidation is more capable on every axis that matters here. The one
thing PMI would add — automatic, criterion-free promotion — is the thing to
refuse.

**Fourth: the interference claim is unsupported.** The abstract claims the design
is "reducing information conflicts and averting memory overflow" (p. 1). No
experiment in the paper measures conflict or overflow. There is no
interference model to steal, only additive superposition with no conflict
detection. If the plan wants an interference/competition model for the memory
tier, it is not in this paper.

Where the paper agrees: bounded capacity, restricted write access, and
retrieval selection are all consistent with the existing commitments.

## 5. Evidence quality

**Peer reviewed.** The PDF header reads "Published as a conference paper at ICLR
2024" on every page (p. 1). arXiv:2310.09297v2, 20 May 2024. This is not a
preprint.

Tasks: Sort-of-CLEVR (visual relational QA), bAbI-20k (text QA), equilateral
triangle detection, Enwik8 / WikiText-103 / PG-19 language modeling, CIFAR-10.

**Seeds: one, for almost everything.** Tables 7 and 8 list "Seed 1" for bAbI,
Sort-of-CLEVR, Triangle, CIFAR-10, Enwik8, WikiText-103 and PG-19 (p. 19). Only
bAbI reports 10 runs (Table 1 p. 7, Table 9 p. 22). Every Sort-of-CLEVR number,
every language-modeling number, the CIFAR-10 table and the entire ablation
Table 5 are single-seed point estimates with no error bars.

**The bAbI headline is one task.** Table 9 (p. 22) breaks the 20 tasks out:
17 tasks at or near 0% error, and Task 16 (Basic Induction) at **47.89 ± 1.47%**
in every one of the 10 runs — "Failed task(>5%): 1" across the board. Task 16
alone contributes 47.89/20 = 2.39 of the reported 2.55% mean. The advertised
"2.55 ± 0.11 vs TR+HSW 3.6 ± 0.46" is therefore not a broad improvement; it is
19 solved tasks plus one task at chance, and the tight std comes from a
consistent catastrophic failure, not from stability. The paper does not discuss
Task 16 anywhere.

**CIFAR-10 undercuts the generality claim.** CNN PMI 78.69% vs CNN MLP 78.61% —
0.08 points for 1.75M parameters against 0.11M, a 16x increase (Table 6, p. 17).
The text calls this "superior performance" and "further underscore[s] the
universality of our PMI module." PMI-TR's 79.12% is also far below what a small
ResNet reaches on CIFAR-10, so the whole comparison sits in a regime where the
architecture is not the binding constraint.

**Baselines are old and partly weak.** bAbI comparisons run to DNC (2016), H-Mem
(2020), NUTM (2020), TR+HSW (2022) (Table 1, p. 7). The language-modeling
baseline TIMS+HSW is reported at 1.36 BPC on Enwik8 and 36.7 test PPL on
WikiText-103 (Tables 2-3, p. 8) — implausibly bad, and used as the headline
comparison against Goyal et al. Cross-codebase LM comparisons come with no
training-budget, context-length, or memory-length normalization.

**The ablation's cognitive claim is numerology.** "The optimal results are
achieved at N = 8 and M = 5, aligning with discoveries in cognitive
neuroscience" (p. 8) is drawn from Table 5, where the Sort-of-CLEVR binary
column swings 77.12 -> 87.61 -> 79.64 across configurations with no repeats. The
Miller's-Law framing (7±2, p. 3) is retrofitted onto single-seed variance.

**Admitted limitations:** the authors describe the work as "a preliminary
exploration" and "exploratively apply" (pp. 1, 6), and note capacity is not
monotone in performance (p. 8).

**Unadmitted:** single seed almost everywhere; Task 16's total failure; the
0.08% CIFAR result presented as success; no measurement of the "conflict
reduction" and "overflow avoidance" claimed in the abstract; Eq. 7's outer
product is dimensionally unspecified; `sk` is `R^{N×(T+N)}` in the main text
(p. 4) and `R^{N×T}` in Algorithm 1 (p. 14); C in the text is M in the tables;
α is a "hyper-parameter" in the text and an "Initial α value" in the tables.

**Is the headline supported?** Partially. "PMI enhancements consistently outshine
their original counterparts significantly" (p. 1) holds for bAbI (10 runs, real
margin) and is plausible for the LM perplexities. It does not hold for CIFAR-10,
and the Sort-of-CLEVR / triangle / ablation results are too thin to carry the
weight the discussion places on them.

## 6. Do not take

- **The outer-product LTM** (Eq. 7, p. 4). Tensor-product superposition of typed
  records into a dense blob is the opposite of what a provenance-preserving
  SQLite store is for, and the paper itself discards the structure by averaging
  fragments before reading (Eq. 9).
- **Unconditional promotion.** No criterion on WM->LTM. Navi-Brain must have a
  criterion; the paper offers none to copy.
- **The gating mechanism** (p. 18) as anything but a slogan. It needs learned
  `W^I`, `W^F`, backprop, and it produces correlated input/forget gates. The
  transferable residue is one sentence: retain by default.
- **The N=8 / C=5 / k=5 constants as law.** They are single-seed optima on
  bAbI-sized problems, dressed in Miller's Law after the fact. Treat as an order
  of magnitude, not a setting.
- **Any claim that this validates durable memory.** It validates within-episode
  scratch hierarchy. See section 4.
- **Learned content-based addressing.** Requires an embedding index and gives no
  demonstrated advantage over hand-weighted scoring at N=8.
- **The "reduces information conflicts" framing.** Unmeasured; there is no
  interference model here.
- Anything requiring backprop, GPU training, or 200-epoch runs — the background
  workers are free/local models with no weight updates.

## 7. Key citations

- "Initialize the working memory matrix Mw and the long-term memory matrix Ml,
  respectively, guaranteeing their universal sharing across all layers
  encompassed within our framework" — memory is initialized per input, shared
  across layers, not across examples (Algorithm 1, p. 14).
- "Mw^{t-1}, Mw^t ∈ R^{B×N×Dm} represent the previous and updated working
  memory" — the batch dimension proves memory cannot persist across examples
  (Appendix D.1, p. 18).
- "Construct a set Ft containing the indices of the k selected specialists with
  the top-k largest values of sk ... s*k = s[n,t] if t ∈ Ft, else 0" — the entire
  competition mechanism; losers are zeroed, not queued (Algorithm 1, p. 14).
- "Ml^t = LN3(Mw^t ⊗ Ml^{t-1}) + Ml^{t-1}" — promotion to long-term memory is
  unconditional and has no selection criterion (Eq. 7, p. 4).
- "In practice, we set b_i = 0, b_f = 1" — the forget gate is biased open;
  retention is the default and there is no time-based decay anywhere (p. 18).
- "M̂l = (1/C) Σ_{i=1}^{C} Ml[i,:,:]" — the advertised higher-order 3D structure
  is collapsed by a plain mean before it is ever read (Eq. 9, p. 4).
- "memory persistence markedly improves the performance and speed of convergence
  in relational inference tasks ... by 7.32%, 6.88% over non-globally shared
  cases. Notably, independent memory modules result in an eightfold increase in
  trainable parameters" — persistence beats rebuild-from-scratch at 1/7th the
  parameters (p. 8; Table 5, p. 9).
- "16:Basic Induction 48.21 47.12 ... 47.89±1.47 / Failed task(>5%): 1" — the
  2.55% bAbI mean is 19 solved tasks plus one at chance (Table 9, p. 22).
- "CNN PMI (ours) 78.69 / CNN MLP 78.61; Params 1.75M / 0.11M" — 0.08 points for
  16x the parameters, presented as evidence of universality (Table 6, p. 17).
- "greater memory capacity doesn't necessarily equate to better performance. The
  optimal results are achieved at N = 8 and M = 5, aligning with discoveries in
  cognitive neuroscience" — single-seed table, retrofitted to Miller's Law
  (p. 8).
