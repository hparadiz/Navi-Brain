# Record #78 — Grounding Language about Belief in a Bayesian Theory-of-Mind (Ying, Zhi-Xuan, Wong, Mansinghka & Tenenbaum, CogSci 2024)

The companion to #77: that paper parsed language *into* a world model, this one
parses language *about mental states* and scores it against one. Its scoring
mechanism is the single most useful safety pattern in the whole ToM block.

## 1. Mechanism

Three stages (Figure 1):

1. **Translate** a natural-language belief statement into first-order epistemic
   logic, using an LLM:

   > "The player believes that there is a key in either box 2 or box 3."
   > → `(believes player (exists (?k - key) (or (inside ?k box2) (inside ?k box3))))`

2. **Infer** a posterior over the agent's joint (goal, belief, plan) hypotheses
   from observed actions, by Bayesian inverse planning (#75's machinery).

3. **Evaluate** the formula against that posterior. `P(ψ | a_{1:T})` is just the
   **summed posterior mass of the hypotheses in which ψ holds**. In the worked
   figure, four hypotheses each at p=0.23; ψ₁ is satisfied by all four → 0.92;
   ψ₂ by two → 0.46.

The LLM never says what the agent believes. It converts an English sentence into
a testable formula, and a number comes back from the posterior.

**Functional role semantics.** The framing: a belief statement is not only a
claim about which propositions the agent holds true, it "implies rationality
constraints on how the agent is likely to plan and act given their goals." So the
meaning of "he believes X" is cashed out as *the set of behaviours that would be
coherent if X were held*, which is why the statement can be scored against
observed actions at all.

**Domain.** A doors-and-keys gridworld with four gems, keys hidden in **opaque
boxes**. The player knows where the keys are; the observer does not. So the
observer must infer the player's knowledge from instrumental behaviour.

**Baselines**, chosen to isolate what mentalizing contributes:
- **Omniscient Observer** — knows the truth of every statement; models what
  epistemic logic deduces if the agent knows everything and so does the observer.
- **Ignorant Observer** — rates everything false, negation-as-failure.
- **Non-Mentalizing Observer** — rates by prior probability under a uniform prior
  over states.
- **Heuristic Mentalizer** — assumes the agent always moves physically closer to
  its goal, **ignoring instrumental actions like picking up keys**.

**Results** (n=100 Prolific, each rating 9 of 18 scenarios, bootstrap CIs):

| | Goal attributions | Belief statements |
|---|---|---|
| **Full BToM** (uniform over statements, U_ψ) | **0.93** [0.91, 0.94] | **0.92** [0.91, 0.93] |
| Full BToM (uniform over states, U_S0) | — | 0.86 [0.85, 0.87] |
| Heuristic Mentalizer | 0.17 [0.13, 0.19] | 0.04 [0.02, 0.06] |
| Non-mentalizing / logical baselines | — | 0.19 [−0.03, 0.40] … 0.64 [0.48, 0.75] |

The Heuristic Mentalizer result is the sharpest: dropping *instrumental* actions —
picking up a key is not moving toward the gem, it is moving toward being able to
reach the gem — takes goal attribution from 0.93 to **0.17**. Means-ends
coherence is not a refinement; it is nearly the whole signal.

**The negative-evidence pattern, again.** "Once the player walks down the
corridor past box 1, both humans and our model rate statement 1 ('The player
believes that there is a blue key in box 1.') to be highly improbable. This is
because the player needs a blue key to reach the inferred goal and a rational
agent would not walk past box 1 if they knew it contained a blue key."

**The prior finding.** Uniform-over-statements beat uniform-over-states because
participants ignored base rates: statements true in more possible worlds ("a red
key in box 1 **or** box 2") have a higher base rate, and people did not credit
them for it. "They tended to rate a statement more highly only if there was more
evidence for that statement... it suggests that people are only willing to say
that an agent believes φ if there is evidence for that belief." The authors note
this "is not Bayesian in the orthodox sense."

## 2. Transferable to Navi-Brain

### (a) Score belief claims, never generate them — this is the safety pattern

Every earlier record raised the same worry from a different angle: #74's MNO says
models of other agents are never observed, #77 §2e showed an LLM producing
confidently inverted attributions, and #72 §2c argued for a confidence ceiling on
belief claims. This paper supplies the mechanism that makes all three enforceable.

**A claim about Henry's beliefs enters the system only as a formula to be
evaluated, and its confidence is the posterior mass that satisfies it.**

That is a hard architectural boundary rather than a policy:
- The LLM's output is a *candidate proposition*, syntactically checked — which is
  exactly the `FreeModelWorker` contract ("schema-valid JSON only, proposals not
  facts").
- The confidence attached is computed, not asserted. No model ever writes a
  number describing how sure it is about a person's mind.
- If the posterior has no mass either way, the answer is a low score for *both* a
  statement and its negation — which is the correct output and is what #72 §2e's
  `no_rational_interpretation` terminal state should return.

`SelfModelFact` already requires evidence and confidence on stored claims. This
gives the other-model a principled source for the confidence number instead of a
model's self-report, and it is the difference between a user model and a rumour
mill.

### (b) The normalized-likelihood result is a directive for the semantic tier

Participants scored statements by *evidence for*, not by *probability of*. A
statement true in many worlds got no credit for breadth.

This aligns exactly with a rule Navi already enforces and gives it a new
application. `docs/architecture-gaps.md:37` records that direct semantic writes
require a source event or memory, and `:31-33` records what happened when
unsourced material was consolidated. The failure mode there — "confident
inventions about mechanisms that do not exist" — is the base-rate failure in
another costume: vague claims that are true in many worlds survive consolidation
because nothing contradicts them.

For an other-model, the rule follows directly: **a vague attribution about Henry
should score lower than a specific one supported by the same evidence.** "He
cares about the project" is nearly unfalsifiable and should be cheap to hold and
worthless to store. "He is trying to get the heartbeat service to survive a
restart" is narrow, evidenced, and worth keeping. Scoring by normalized
likelihood rather than posterior probability produces that ordering for free.

### (c) Instrumental actions carry the signal — and Navi cannot see them

Goal attribution collapsing from 0.93 to 0.17 when instrumental actions are
ignored is the strongest quantitative result in this record. Picking up a key is
not progress toward the gem; it is progress toward being *able* to make progress.

Henry's day is overwhelmingly instrumental. Opening a terminal, checking a log,
starting a service, reading a man page, running `git status` — none of these move
toward any goal in a surface sense, and all of them would be the actual evidence.

**And essentially none of it is observable.** `CommandSense` and the
`navi-senses` daemon return output from commands **Navi** chose to run, not
Henry's command trajectory. `shell_activity`, `terminal_activity` and
`process_activity` carry only the age of the newest write — that *something*
happened, never what. So the channel this paper identifies as carrying
five-sixths of the goal signal is, for Navi today, a timestamp.

That is the honest re-ranking, and it is uncomfortable: the informative channel
is unavailable, and the available channel (`SocialFeedback`'s reply-within-120s)
is the noisy one this paper says carries little. The two conclusions that follow
are (i) explicit speech is the only high-information goal evidence Navi actually
has, which raises the value of the parser in #77 §2c considerably, and (ii) any
claim that a richer other-model would work well rests on a perception grant that
does not exist yet and should be argued for on its own terms.

### (d) Non-response as negative evidence — the third category

Three papers now make the same point: #71's targeted analysis (going *around*
the obstacle disambiguates), #77's walked-past-silver, and here "a rational agent
would not walk past box 1 if they knew it contained a blue key." **What someone
did not do is evidence.**

`SocialFeedback::closeWindows()` has exactly two readings of silence:
`engagement = 0.0` (he was there and did not respond) or `inconclusive` (nobody
was detected, "absence of evidence, kept out of the evidence"). Both are correct
as far as they go and both discard the third reading: *he was there, he heard,
and he did not respond — which is informative about what he believed the line
required.* Under a functional-role semantics, non-response is a rationality
constraint violation for some belief hypotheses and consistent with others.

This does not need new sensors. It needs the inconclusive/zero dichotomy replaced
by a likelihood term.

### (e) The parser is small, and Navi can host it

Same as #77: the LLM does translation only. Statements → epistemic logic is a
constrained, checkable transformation well within a small local model's reach —
`LocalModelClient` / `LocalModelWorker` already exist, and the vision gate already
runs a local Gemma 3 4B. The contended big slot
(`docs/architecture-gaps.md:271-272`) is not on this path.

## 3. Seam

Primary: **`other-model`** — supplies the belief-evaluation mechanism.

Also touches:
- `self-model` — confidence-from-posterior-mass replaces confidence-from-assertion
  (§2a).
- `memory-tier` — normalized likelihood as the write criterion for attributions
  (§2b).
- `perception` — instrumental action is the primary evidence class and is
  currently unobservable; a grant question, not a wiring question (§2c).
- `social-feedback` — non-response as a likelihood term, not a zero or a null
  (§2d).
- `worker-schema` — the parser is a bounded proposal worker.

## 4. Challenge to the current plan

**Sharpest: the plan's evidence hierarchy is upside down for this purpose.**
`docs/architecture-gaps.md` treats the social loop — speak, wait, measure
engagement — as the place Navi learns about Henry, and rightly notes the
measurement is unreliable. This paper says the diagnostic channel is
*instrumental action*, and quantifies the difference: 0.93 versus 0.17. Navi is
mining the noisy channel — but, per §2c, the informative one is not merely
unmined, it is unavailable. So the correct conclusion is not "attach the
other-model to command observation" but "the only high-information goal evidence
Navi has today is what Henry says out loud, and the plan should be honest that a
richer model is blocked on a perception grant rather than on inference."

**Second: the language papers are working on an easier problem than the 2011 and
2017 papers, and the plan should not read the block as monotonic progress.** The
authors state the limit plainly: the model "only explains the deterministic
beliefs of other agents, under the assumption that what other agents believe is
what they know," and the experimental setup makes the player omniscient about key
locations. So there are no false beliefs here at all. #72 and #73 handled
genuinely false beliefs — that was their entire contribution — and the
language-grounded successors gave that back to gain compositional statements. The
practical consequence for Navi: the case that matters most, *Henry believes
something about this machine that is not true*, is handled by the 2011/2017
formalism and not by the 2024 one. Do not assume the newest paper subsumes the
older ones.

**Third: an evaluation architecture needs a hypothesis space to evaluate
against, and that is still missing.** Summing posterior mass is only meaningful
if the posterior is over something real. Here the hypothesis space is four gems
and a handful of key placements. For Navi it is "what is Henry doing," which #75
§5 and #76 §5 both explicitly leave open and #77 §2c suggests answering from his
own speech. The evaluation mechanism in this paper is excellent and it is the
*second* thing to build.

**Fourth: the strongest baseline is a mystery worth noting.** One non-mentalizing
baseline reaches 0.64 with a wide CI, and one has a CI spanning zero. A
purely-logical omniscient observer getting into the 0.6s on belief statements
means a substantial fraction of the stimuli are answerable without mentalizing at
all. The headline gap (0.92 vs 0.04 against the Heuristic Mentalizer) is the most
flattering framing available; the honest gap against the best baseline is much
smaller.

**Agreement:** the "LLM proposes, symbolic layer scores" split is the only
pattern in this corpus that lets Navi use language about Henry without letting a
model author claims about him. It fits the existing worker discipline exactly.

## 5. Evidence quality

**Venue:** CogSci 2024 proceedings, 7 pages. Refereed conference, short format.

**Strengths:**
- **n=100** on Prolific, each rating 9 of 18 scenarios, paid $15/hr with an
  incentive bonus for correct goal inference. The best-powered human study in the
  ToM block by a wide margin — #71-#73 ran 16-27, #75 ran 8.
- Four baselines spanning genuinely different failure modes: omniscient logic,
  negation-as-failure logic, no mentalizing, and shallow mentalizing.
- Bootstrap CIs on everything.
- The prior comparison (U_ψ vs U_S0) is a real finding about human judgement that
  the authors did not need to report and that complicates their own framework.
- Qualitative walkthroughs tied to specific judgement points.

**Where it is thin:**
- **No false beliefs.** The paper is about belief and the agent is stipulated to
  know the truth. Named as a limitation, but it is a large one.
- **Belief statements are hand-authored** and paired to the domain; there is no
  test of the parser on statements it was not designed for, and no reported
  translation error rate.
- **18 scenarios**, one gridworld domain, four gems.
- **Correlations against per-stimulus means** across participants, the standard
  aggregation inflation.
- **The best non-mentalizing baseline reaches ~0.64**, which the abstract's
  framing ("much better fit than the baselines") does not convey.
- **No cross-validation.** Unlike #73, no held-out evaluation of the fitted
  components.
- **The LLM translation step is unevaluated in isolation.** Same gap as #77 —
  the architecture's dependency on the parser is load-bearing and unmeasured.

**Is the headline supported?** That belief attributions require joint
goal-belief-plan inference, and that instrumental reasoning is where the signal
lives, is well supported — the 0.93 → 0.17 collapse is a large, clean effect on a
decent sample. That this constitutes a semantics for belief language is a
philosophical claim the experiment cannot settle, and it rests on a domain
without false beliefs.

## 6. Do not take

- **The claim that this handles belief language generally.** It handles
  statements about what an agent knows, in a domain where knowledge and truth
  coincide. "He thinks the service is running, but it isn't" — the case Navi
  actually needs — is outside this model.
- **Epistemic logic formulas as a storage format.** The transferable idea is
  *proposition with a computed score*; nested `(believes player (exists ...))`
  syntax buys nothing for a depth-1 model over an enumerated goal set and would
  invite the nesting #74 §6 rejects.
- **Uniform priors over hypotheses.** Both variants tested here are uniform;
  Navi has real prior information about Henry (his projects, his hours, his
  habits) and would be discarding it. But note §2b: whatever the prior, the
  *score* should be evidence-driven.
- **The 0.92/0.93 as a ceiling for a real deployment.** 18 gridworld scenarios,
  hand-written statements, aggregated ratings.
- **Any behaviour keyed to a low-mass belief attribution.** If the posterior does
  not concentrate, the correct action is silence, not a hedged remark about what
  Henry might be thinking. The scoring mechanism makes "I don't know" cheap to
  detect; the plan should make it cheap to act on.
- **Storing belief attributions durably at all, without expiry.** Same objection
  as #72 §6, now sharper: this model's beliefs are about a moment. A summed
  posterior mass computed at 14:00 is not a fact about Henry.

## 7. Key citations

- The scoring mechanism: belief statements are evaluated "with respect to the
  inferences produced by a probabilistic programming architecture for Bayesian
  inverse planning," with `P(ψ|a_{1:T})` computed as the summed posterior mass of
  satisfying hypotheses (Fig. 1).
- Functional role semantics: belief statements are "not just claims about which
  propositions are thought to be true by an agent... but also imply rationality
  constraints on how the agent is likely to plan and act given their goals."
- The instrumental-action lesion: the Heuristic Mentalizer "assumes that the
  agents will always move physically closer to their goal, ignoring instrumental
  actions like picking up keys. This baseline tests the importance of accounting
  for means-ends coherence" — goal attribution 0.17 [0.13, 0.19] versus the full
  model's 0.93 [0.91, 0.94] (Table 1).
- Negative evidence from inaction: "a rational agent would not walk past box 1 if
  they knew it contained a blue key" (Results).
- The base-rate finding: participants "tended to rate a statement more highly only
  if there was more evidence for that statement... it suggests that people are
  only willing to say that an agent believes φ if there is evidence for that
  belief," and "this is not Bayesian in the orthodox sense" (Quantitative
  Analysis).
- Gradedness against logic: "Human judgments about what agents believe are not
  all-or-nothing phenomena. Our account provides a semantics for such graded
  judgments, unlike logical models which judge statements to be either false or
  true."
- The scope limitation, in the authors' words: "A key limitation of our current
  model is that it only explains the deterministic beliefs of other agents, under
  the assumption that what other agents believe is what they know... People have
  false beliefs, and we form sentences describing them all the time" (Discussion).
- What a richer account would need: "One that models our uncertainty about
  other's uncertainty (Baker et al., 2017; Gmytrasiewicz & Doshi, 2005), as well
  as the abstract ways we represent both the world and each others' minds"
  (Discussion) — i.e. #73 and #74.
- Sample: "We recruited 100 US participants through Prolific... Each participant
  rated 9 out of the 18 scenarios," paid $15/hr with a correctness bonus
  (Participants).
